# angrCTF_solutions

This repository gathers the solutions to the exercises proposed in [https://angr.oregonctf.org/](https://angr.oregonctf.org/).

## Installation

To me, the most efficient way to install angr is under a virtual environment, as it is safer, and it won't mess up with existing global configurations:

`
$ python3 -m venv angr_playground
$ source angr_playground/bin/activate
$ pip install angr
`
